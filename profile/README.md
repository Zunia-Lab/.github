## Built for Cosmos / IBC

Zunia supports the standard Cosmos wallet interface, native IBC transfers, WalletConnect on mobile, and hardware wallets (Ledger, Keystone). Chain metadata ships from our [chain registry](https://github.com/zunialab/zunia-chain-registry) without requiring an app update.
